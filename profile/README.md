# Smart Install Maker - Package desk for a setup you keep

Wizard screens should stay on a setup project you keep. Mixed folders wait off the live desk.

## Session Card

| Slice | What you do in Smart Install Maker | What remains |
|-------|------------------------------------|--------------|
| Arrival | Open Smart Install Maker on a package you keep and name the wizard session | A titled setup project |
| Focus | Keep wizard screens on one Smart Install Maker shop package | A short page list |
| Check | Read the pages before you ship a package you own | A confirmed package desk |
| Handoff | Leave the Smart Install Maker setup project on that desk | A note for the next visit |

## How Smart Install Maker Sits

Smart Install Maker does not replace the files you already keep for that package. It sits beside them as a named wizard session for a Smart Install Maker shop package you own.

## Traffic Light

| Signal | On the Smart Install Maker package desk | What you do |
|--------|-----------------------------------------|-------------|
| Green | Named project, pages on your package | Continue the same wizard session |
| Amber | Pages from two packages mixed | Split the set before a large change |
| Red | No title, mixed folders everywhere | Stop and name the setup project first |
| Clear | Handoff written, page list short | Close Smart Install Maker and leave the desk |

## Open Order

1. Open the last Smart Install Maker session on a package you keep, not a new empty wizard.
2. Read the setup project and the last handoff.
3. Finish one visible page inside Smart Install Maker package desk.
4. Write what changed on a package you own, then close with fewer mixed folders than you found.
5. If the wizard session feels crowded, drop anything that belongs to a different Smart Install Maker job.

## After a Week

A week in Smart Install Maker is not more live pages. It is the same setup project, a shorter page list, and a note that still makes sense on Monday. Leave the wizard session quieter than the folders you opened.

## Sign-off

- [ ] The Smart Install Maker project name is short enough to scan
- [ ] Only a package you keep is on the desk
- [ ] A second person can read the last page note
- [ ] The last Smart Install Maker session still opens after a restart
- [ ] Finished pages are off the live set

## Field Note

Smart Install Maker is easier to trust when the package desk stays smaller than the mixed folders around it. Name the wizard session, keep pages on a package you own, finish one visible screen, and write what changed.
